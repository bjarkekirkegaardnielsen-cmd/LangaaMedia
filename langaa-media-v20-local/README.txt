UPLOAD TIL NETLIFY
1. Log ind på Netlify.
2. Vælg Add new project / Deploy manually.
3. Træk hele mappen eller ZIP-filens udpakkede indhold ind.
4. Netlify giver dig en midlertidig adresse.
5. Tilknyt dit eget domæne under Domain management.

KONTAKTFORMULAR
Formularen på kontakt.html bruger Netlify Forms.
Efter første deploy kan formularbeskeder ses i Netlify under Forms.
Du kan sætte e-mailnotifikationer op i Netlify.

RETTELSER
Tekster ændres direkte i de enkelte .html-filer.
Farver, størrelser og layout ændres i style.css.

BILLEDER
Der er med vilje ingen AI- eller stockbilleder i denne version.
Når du har egne billeder, kan de lægges ind i en /images-mappe og placeres på siderne.
